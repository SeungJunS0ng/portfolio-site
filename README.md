# Developer Portfolio

송승준의 백엔드 개발자 포트폴리오 웹사이트입니다.

## 구성

- One Page 섹션 네비게이션: About, Experience, Skills, Projects, Archive, Contact
- 데이터 기반 프로젝트·기술 스택·경험 렌더링
- Archive 전용 경로 준비 (`/archive`)
- 반응형 UI와 CSS Modules 기반 스타일링

## 기술 스택

React, TypeScript, Vite, CSS Modules, React Router

## 실행

```bash
npm install
npm run dev
```
